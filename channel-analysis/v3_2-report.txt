WIN-RATE DEFINITION CORRECTION (applies to V3.1 too): this script counts a
win as adjusted R > 0, a loss as R < 0, and R == 0 as breakeven. The V3.1
report counted wins from the ORIGINAL outcome (out['win']), so its 51.4%
is the PRE-simulation win rate. After the trailing stop converts some
outcomes to breakeven, the V3.1 strategy's true win rate is 45.9% with 30
breakevens (16.4%). Average R (+0.411) is unaffected and is the correct
expectancy measure. The same applies to every trailing-BE / partial-TP
row in this report: win rate is post-simulation, breakevens are shown.
